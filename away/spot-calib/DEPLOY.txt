==========================================================================================

WHAT IT DOES
calib.py now writes the right DMX layout for each fixture: the 4 LM70S heads keep their 14-channel bytes
(byte-for-byte the same as today -- tested), the 2 Focus Spots ('type': 'focus17' in the node config) get the
17-channel layout hub_dmx.focus_out uses (pan/tilt, colour slot, gobo, gobo rot, focus, shutter 12 = open,
dimmer, UV shutter, UV, motor speed). Before this, "aim 5" would have sent head bytes to a spot.

New modes (Spot 1 = the 1st focus17 fixture = fixture 5, Spot 2 = fixture 6):
  python3 calib.py spot 1        Spot 1 alone: open beam, colour slot 97 (deep blue-violet -- never white),
                                 dimmer 60%, on its saved aim (spot_fx 'hold'; Spot 2 = per_head '5' hold).
  python3 calib.py aimspot 2     Spot 2 follows bridge/calib_aim.json. Either {"pan": .., "tilt": ..} (16-bit)
                                 or {"az": .., "lean": ..} (degrees -- the same numbers spot_fx 'hold' stores),
                                 plus optional "color", "gobo", "gobo_rot", "focus" (0-255), "uv" (0-1).
                                 The log (bridge/outbox/calib.txt) shows az + lean for every nudge, so Claude can
                                 copy the final numbers straight into spot_fx hold.
  python3 calib.py uvaim 2       Same, UV only (beam dark, dimmer 0, UV full unless "uv" says otherwise).
  touch calib.stop               stops any of them (as before). Head 3: use the existing "aim 3" / "head 3".
Spot 2 on -> the log says "ceiling fan OFF please" (AGENTS rule). Colour slots 0-14 (open/white) are swapped
for slot 97. Shutter is only ever 12 (open) or 0 -- calibration never strobes. The node still enforces every
pan window, lean cap and avoid zone on top.

  2. python3 calib.py spot 1  -> check it lights alone, purple-blue, on its old curtain aim. touch calib.stop.

     to walk it to the new spot (Spot 2 was moved this morning). Read the az/lean off the log, save them as
     spot_fx per_head "5" hold. Same with uvaim 2 for the UV aim.

  elsewhere, so write an az/lean (or a new pan/tilt) into it before or right after starting aimspot.
